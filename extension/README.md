# VideoEnglish Chrome 插件

在 YouTube / B站 **原生页面** 边看视频边收藏生词，或在 **任意英文网页** 阅读学习，后端 FSRS 科学复习。

## 安装

1. 启动后端：
   ```bash
   uvicorn app.main:app --reload
   ```

2. Chrome 打开 `chrome://extensions/`

3. 开启「开发者模式」→「加载已解压的扩展程序」

4. 选择本项目的 `extension` 文件夹

## 视频学习

1. 打开任意 YouTube 或 B站 视频（YouTube 需开启 CC 字幕）
2. 点击页面右侧 **「学」** 按钮打开侧边栏
3. 字幕自动加载并翻译，随播放进度高亮
4. **点击任意单词** → 查看释义 → **★ 收藏生词**
5. 打开 http://127.0.0.1:8000/vocab 进行 FSRS 复习

## 网页阅读

1. 打开任意英文文章页面（Medium、新闻、博客等）
2. 点击右侧 **「读」** 按钮打开阅读侧边栏
3. 自动提取正文、翻译、点词查义、AI 解释
4. **💾 保存到书库** → 在 http://127.0.0.1:8000/reader 完整阅读（进度/笔记/高亮）

## B站说明

B站字幕需要登录 Cookie。可在 Web 端 http://127.0.0.1:8000 扫码登录 B 站。

## 设置

点击浏览器工具栏插件图标，可修改后端 API 地址（默认 `http://127.0.0.1:8000`）。
